# Assets

Placeholder directory structure for the asset pipeline (Graphics Step 1).

Everything here is served from `/assets/...` by Vite (this `public/` folder).

## Structure

- `blocks/` — block textures (ids: `block.grass`, `block.dirt`, `block.stone`, ...)
- `characters/` — player and future NPC/animal sprites
- `environment/` — decoration / world objects (future)
- `background/` — sky, parallax mountains, clouds (future)
- `effects/` — particles / foreground effects (future)

## Licensing rules

- No assets copied from Minecraft, Terraria, Stardew Valley, or any other
  commercial game.
- Every shipped asset must carry source/license metadata in
  `src/assets/assetRegistry.ts` (author, source, license, attribution).
- Until an asset file exists for an id, the renderer draws the block's flat
  color — the game never breaks on a missing asset.

## Status (Step 2)

Real procedural textures exist for the three terrain blocks:

- `blocks/grass.png` — grass (green, value noise)
- `blocks/dirt.png` — dirt (brown, value noise)
- `blocks/stone.png` — stone (gray, value noise)

They are generated by `scripts/generateBlockTextures.mjs` (pure Node, no
dependencies) and are original to this project. If any file is removed the
renderer silently falls back to the block's flat color — the game never breaks.
