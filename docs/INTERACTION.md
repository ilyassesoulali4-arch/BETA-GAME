# التفاعل مع العالم (World Interaction)

## التحكم

- **زر الفأرة الأيسر:** هدم الكتلة المستهدفة (تعمل على الكتل الصلبة فقط).
- **زر الفأرة الأيمن:** وضع كتلة **عشب (Grass)** في الخلية المستهدفة إن كانت فارغة
  ولا تتقاطع مع جسم اللاعب.
- الإجراء يحدث عند **الضغطة** (press edge) وليس أثناء الإمساك — لا يتكرر الهدم/الوضع.

## الفصل بين الطبقات

| الملف | الدور |
|---|---|
| `pointer.ts` | حالة الفأرة الخام: موضع (إحداثيات شاشة) + أزرار |
| `blockInteraction.ts` | الترجمة إلى خلية كتلة + السياسة (متى يُهدم/يُوضع) |
| `world.ts` (`setBlockAt`) | المسار الوحيد لتعديل العالم |

## الاستهداف

1. شاشة → عالم: `worldPoint = pointer + camera`.
2. عالم → خلية: `cell = floor(worldPoint / block.size)`.
3. `world.setBlockAt/getBlockAt` تعالج حدود الوحدات داخلياً → التفاعل يعمل عبر الحدود تلقائياً.

## التكامل المستقبلي

| النظام | نقطة الربط |
|---|---|
| **Inventory** | يحل محل `placementBlock` الثابت: يوفّر id الكتلة المراد وضعها + يخصم العدد عند الوضع الناجح |
| **Tools** | تُربط بـ `destroyBlock`: تحدد سرعة وقوة الهدم (وقت كسر بدل إزالة فورية) |
| **أنواع كتل أخرى** | تُضاف إلى سجل `blockTypes` فقط |

ملاحظة: `destroyBlock` و `placeBlock` طريقتان خاصتان في `blockInteraction.ts` —
هما التماسّان اللذان سيتصل بهما المخزون والأدوات.
