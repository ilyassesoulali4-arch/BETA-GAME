# خارطة الطريق — Endless World

## مكتمل

- **0.1** — لاعب، أرضية، كاميرا، حركة، حفظ بذرة.
- **0.2** — تضاريس إجرائية حتمية (height-map) مرتبطة بالبذرة، تحكم WASD، تحضير بنية الوحدات.
- **0.3** — عالم بلا حدود، عرض حسب الكاميرا (المرئي فقط)، وحدة `chunk.ts` وتوثيق المعمارية (ARCHITECTURE.md).
- **0.4** — نظام كتل كامل: تعريفات (`blockTypes`)، بيانات (`Chunk`)، توليد (`chunkGenerator`)، تخزين (`World`)، عرض (`blockRenderer`). توثيق BLOCK_SYSTEM.md.
- **0.5** — أول نظام تفاعل: هدم بالزر الأيسر، وضع عشب بالزر الأيمن، تمييز الخلية المستهدفة. فصل: `pointer` / `blockInteraction` / `setBlockAt`. توثيق INTERACTION.md.
- **0.5.1** — وحدات ثنائية الأبعاد `(chunkIndex, chunkY)`: إزالة القيد الرأسي — البناء يرتفع بلا سقف محدد بعمق وحدة واحدة.
- **0.5.2** — حفظ/تحميل تلقائي: فروق الوحدات المتأثرة + موضع اللاعب عبر `saveSystem.ts` (تنسيق + تحقق من الإصدار + localStorage).

## قادم (بالتدرج، كل نسخة خطوة صغيرة)

- نظام تحميل/تفريغ الوحدات (Chunk Loading) حول اللاعب.
- إضافة الكائنات حتمياً داخل الوحدات عند النضج.
